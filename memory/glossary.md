# 晴域项目术语

| Term | Meaning |
|---|---|
| `wellhong.dev` 首选域名 | Cloudflare Worker/Pages 部署时优先使用的自定义域名区域，由用户确认。 |
| 子域名前缀 | 在 `wellhong.dev` 前选择的项目入口名称，例如 `qingyu`，需要部署前检查可用性。 |
| 回退地址 | 自定义域名未绑定前使用的 `workers.dev` 或 `pages.dev` 地址。 |
